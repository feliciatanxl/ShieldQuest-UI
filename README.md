# ShieldQuest-UI

A cosy, Habbo-style 2D isometric pixel-art neighbourhood adventure set in the Singapore heartlands (**Project SHIELD**).

## Features
- **Landing & Start Screen**: Live animated Block 260 isometric neighbourhood backdrop, pseudonymous display name & optional workshop squad code entry, real-time character customisation, Afternoon (`17:30`) / Evening (`19:15`) mood toggle, and S.H.I.E.L.D. Framework brief.
- **Exact 4-Corner Heartland HUD**:
  - **Top-Left**: Circular wood-framed player portrait, display name, red/teal status bars, silver Shield crest, and Guardian badge slot.
  - **Top-Right**: Interactive `17:30` / `19:15` time & weather pill toggling warm afternoon sunlight and cozy evening dusk with fairy lights & lit HDB windows.
  - **Bottom-Left**: `Current Quest:` tracker (`Find Uncle's EZ-Link` & `The Lookout Dilemma`).
  - **Bottom-Right**: Four pixel-art wooden buttons (`Backpack`, `Wardrobe`, `Map`, `Menu`).
- **Interactive Singapore Neighbourhood**: Walk with **Click/Tap** or **WASD / Arrow keys** (+ `Shift` to run) around the sheltered walkway, HDB void deck (letterboxes, notice board, round stone chess table, community cats), bus bay footpath, and **Sunshine Minimart**.
- **S.H.I.E.L.D. Anchor Mission (*The Lookout Dilemma*)**: Six distinct, non-overlapping interactive competency checks (`S`, `H`, `I`, `E`, `L`, `D`) focused on shop-theft peer-pressure refusal and responsible help-seeking.
